# Tasks Placed by the Language Model — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the user add tasks (length, deadline, chunks, priority) from the terminal and have the language-model planner place them into free time, checked by the validator, with an eval set measuring how well the prompt and few-shot examples work.

**Architecture:** A `Task` dataclass stored in SQLite; task blocks are ordinary planner blocks tagged `Task: <id>` in the event notes. A new module `llm/task_rules.py` holds the pure task logic (remaining minutes, prompt lines, block checks); `llm/week_plan.py` wires it into the prompt, the output schema, the validator and the day-by-day loop. `llm/task_request.py` parses free text into a task; `cli.py` gets a `task` command. `scripts/eval_tasks.py` scores YAML scenarios in `evals/tasks/` against a live model.

**Tech Stack:** Python 3, pydantic 2, sqlite3, pyyaml, pytest (`uv run pytest`), EventKit via pyobjc (not touched by tests).

**Spec:** `docs/superpowers/specs/2026-10-11-tasks-design.md`

## Global Constraints

- No new dependencies (pyyaml, pydantic, anthropic are already in `pyproject.toml`).
- Garmin data does not influence task placement.
- Only blocks carrying `Planned by DayOptimizer` may be deleted; task blocks carry it plus a `Task: <id>` line.
- Out of scope: task dependencies, buffers, repeating tasks, web UI, Reminders sync.
- Code comments and user-facing strings in English, matching the surrounding style (short docstrings that say why).
- Every test uses the isolated `DAYOPTIMIZER_HOME` from `tests/conftest.py`; no test touches the real calendar or a live model.
- Small conventional commits after each task (`feat(tasks): ...`, `test(...)`), per CLAUDE.md.
- Run the full suite with `uv run pytest -q` from the repo root; it is green (365 passed) before Task 1.

## Review Focus

1. A task description without a length: nothing is saved, the user is asked for the length (Task 6 test `test_no_duration_asks_for_it`).
2. A task already past its deadline: still placed (window starts now, deadline check skipped), marked OVERDUE in the prompt (Task 3 tests `test_overdue_task_has_no_end`, `test_task_lines_mark_overdue`).
3. A task partly worked on: past blocks reduce what is left, a block in progress counts up to now (Task 3 test `test_remaining_subtracts_past_and_running_blocks`).
4. The model returns a block for an unknown or finished task, or lists a made-up task as unscheduled: the block is dropped and both are reported (Task 4 test `test_unknown_task_block_and_unscheduled_are_problems`).
5. Existing databases and cached events written before this change (no `task_id`, no `tasks` table) still load (Task 1 test `test_old_rows_without_task_id_still_load`).

```python
    def save_task(self, task: Task) -> None:
        payload = asdict(task)
        for k in _TASK_TIMES:
            if payload[k] is not None:
                payload[k] = payload[k].isoformat()
        self._conn.execute(
            "INSERT INTO tasks(id, data) VALUES(?, ?) ON CONFLICT(id) DO UPDATE SET data=excluded.data",
            (task.id, json.dumps(payload)))
        self._conn.commit()

    def get_task(self, task_id: str) -> Task | None:
        row = self._conn.execute("SELECT data FROM tasks WHERE id=?", (task_id,)).fetchone()
        return _task_from_json(json.loads(row[0])) if row else None

    def open_tasks(self) -> list[Task]:
        tasks = [_task_from_json(json.loads(r[0])) for r in self._conn.execute("SELECT data FROM tasks")]
        return sorted((t for t in tasks if not t.done), key=lambda t: int(t.id[1:]))

    def next_task_id(self) -> str:
        ids = [r[0] for r in self._conn.execute("SELECT id FROM tasks")]
        return f"t{max((int(i[1:]) for i in ids), default=0) + 1}"

    def mark_task_done(self, task_id: str) -> bool:
        task = self.get_task(task_id)
        if task is None:
            return False
        task.done = True
        self.save_task(task)
        return True
```

```python
"""Tasks in the planner: how much of each is left, how the model sees them,
and the checks on the blocks it places for them. llm/week_plan.py calls these;
everything here is pure so it can be tested without a model or a calendar."""
from __future__ import annotations
from datetime import date, datetime
from dayoptimizer.core.models import Event, Task


def minutes(start: datetime, end: datetime) -> int:
    return int((end - start).total_seconds() // 60)


def remaining(tasks: list[Task], events: list[Event], now: datetime) -> dict[str, int]:
    """Minutes still to place for each open task: its length minus what its
    blocks already took. A past block counts as done; one under way counts up
    to now. Future blocks are the old plan and get replaced, so they don't count."""
    left = {t.id: t.duration_min for t in tasks if not t.done}
    for e in events:
        if e.managed and e.task_id in left and e.start < now:
            left[e.task_id] = max(0, left[e.task_id] - minutes(e.start, min(e.end, now)))
    return left


def overdue(task: Task, now: datetime) -> bool:
    return task.due is not None and task.due <= now


def window(task: Task, now: datetime) -> tuple[datetime, datetime | None]:
    """Where the task's blocks may lie. An overdue task has no end: it goes as
    soon as possible instead of being refused."""
    start = max(now, task.not_before) if task.not_before else now
    end = None if task.due is None or overdue(task, now) else task.due
    return start, end


def task_lines(tasks: list[Task], left: dict[str, int], now: datetime) -> list[str]:
    """One line per task with minutes left, as the model reads them."""
    lines = []
    for t in tasks:
        n = left.get(t.id, 0)
        if t.done or n <= 0:
            continue
        parts = [f"- [{t.id}] {t.title} ({t.category}) {n} min left"]
        if overdue(t, now):
            parts.append(f"OVERDUE since {t.due:%a %Y-%m-%d %H:%M}, place it first")
        elif t.due is not None:
            parts.append(f"due {t.due:%a %Y-%m-%d %H:%M}")
        if t.not_before is not None and t.not_before > now:
            parts.append(f"not before {t.not_before:%a %Y-%m-%d %H:%M}")
        split = t.min_chunk_min is not None and t.min_chunk_min < n
        parts.append(f"chunks >= {t.min_chunk_min} min" if split else "in one piece")
        parts.append(f"priority {t.priority}")
        lines.append(", ".join(parts))
    return lines


def block_problem(task: Task | None, category: str, start: datetime, end: datetime,
                  left: int, now: datetime) -> str | None:
    """Why a block for this task can't stay, or None. `left` is what remains of
    the task before this block; only the block that finishes the task may be
    shorter than the minimum chunk."""
    if task is None or task.done:
        return "is not an open task"
    if category != task.category:
        return f"must be in the task's category '{task.category}'"
    lo, hi = window(task, now)
    if start < lo:
        return f"starts before the task may start ({lo:%a %Y-%m-%d %H:%M})"
    if hi is not None and end > hi:
        return f"ends after the task's deadline ({hi:%a %Y-%m-%d %H:%M})"
    length = minutes(start, end)
    if length > left:
        return f"is {length} min but only {left} min of the task are left"
    chunk = task.min_chunk_min or task.duration_min
    if length < chunk and length != left:
        return f"is shorter than the task's minimum chunk of {chunk} min"
    return None


def unplaced(tasks: list[Task], left_after: dict[str, int], listed: set[str],
             last_day: date, now: datetime) -> list[str]:
    """Tasks that had to be finished within the planned days, still have
    minutes left, and were not listed as unscheduled: the model went quiet."""
    out = []
    for t in tasks:
        n = left_after.get(t.id, 0)
        if t.done or n <= 0 or t.id in listed:
            continue
        if overdue(t, now):
            out.append(f"{t.id}: {n} min of '{t.title}' left and it is overdue - "
                       "place them now or list the task in unscheduled")
        elif t.due is not None and t.due.date() <= last_day:
            out.append(f"{t.id}: {n} min of '{t.title}' left before {t.due:%a %Y-%m-%d %H:%M} - "
                       "place them or list the task in unscheduled")
    return out
```

```python
def plan_days(backend, days: list[date], routine: str, categories: list[str], events: list[Event],
              notes: str, rules: list[NoteRule], now: datetime, health: str | None = None,
              history: dict[str, list[date]] | None = None, expect: set[date] | frozenset[date] = frozenset(),
              attempts: int = 3, tasks: list[Task] = (), left: dict[str, int] | None = None,
              few_shot: bool = True) -> tuple[list[PlannedChange], str, list[str], list[str]]:
    """Ask, check, send the problems back; at most `attempts` rounds.
    Returns the calendar changes, the model's summary, what was dropped and the
    tasks it could not fit ("t2: reason").
    A small local model (`one_day_at_a_time`) gets one day per request; what it
    planned for earlier days counts toward the weekly limits and the task
    minutes of later ones."""
    if len(days) > 1 and getattr(backend, "one_day_at_a_time", False):
        history = {c: list(ds) for c, ds in (history or {}).items()}
        left = dict(left or {})
        changes, summaries, dropped, unscheduled = [], [], [], []
        for d in days:
            ch, summary, dr, un = plan_days(backend, [d], routine, categories, events, notes, rules, now,
                                            health, history, expect, attempts, tasks=tasks, left=left,
                                            few_shot=few_shot)
            changes += ch
            dropped += dr
            unscheduled += un
            if summary:
                summaries.append(summary)
            for c in ch:
                if c.kind == "create" and c.new_start is not None:
                    history.setdefault(c.category, []).append(c.new_start.date())
                    if c.task_id in left:
                        left[c.task_id] -= minutes(c.new_start, c.new_end)
        return changes, " ".join(summaries), dropped, unscheduled
    planned = set(days)
    previous = [e for e in events if e.managed and e.start.date() in planned and e.start >= now]
    prompt = build_prompt(days, routine, categories, [e for e in events if e not in previous],
                          previous, now, health, tasks, left)
    request = prompt
    for attempt in range(attempts):
        plan = backend.plan_week(system_prompt(few_shot), request)
        creates, problems = validate(plan, days, categories, events, notes, rules, now, history, expect,
                                     tasks=tasks, left=left)
        if not problems or attempt == attempts - 1:
            return (diff(creates, previous), plan.summary, problems,
                    [f"{u.task_id}: {u.reason}" for u in plan.unscheduled])
        request = (prompt + "\n\n# Your previous answer\n" + plan.model_dump_json()
                   + "\n\n# It broke these rules - return the whole corrected plan\n"
                   + "\n".join(f"- {p}" for p in problems))
    raise AssertionError("unreachable")
```

```python
from __future__ import annotations
import re
from datetime import date, datetime, time
from typing import Literal
from pydantic import BaseModel
from dayoptimizer.core.models import Task
from dayoptimizer.llm.backend import DayWord, resolve_day


class TaskRequest(BaseModel):
    title: str = ""
    category: str = ""
    duration_minutes: int | None = None
    due_day: DayWord | None = None
    due_time: str | None = None
    not_before_day: DayWord | None = None
    min_chunk_minutes: int | None = None
    priority: Literal["low", "normal", "high"] = "normal"
    reply: str | None = None


TASK_SYSTEM = (
    "You turn a user's message about a piece of work into a task for the DayOptimizer planner, "
    "which will place it into free time. The message may be in any language; keep the title in "
    "that language.\n"
    "- title: the work alone, without its day, time or length.\n"
    "- category: exactly one of the listed categories, the closest fit for what the work is.\n"
    "- duration_minutes: total time the work takes: '3h' = 180, 'półtorej godziny' = 90, "
    "'45 min' = 45. Empty if not said.\n"
    "- due_day: the day it must be done by, as a word (today, tomorrow, day_after_tomorrow or a "
    "weekday name); empty when there is no deadline. 'na piątek' / 'by Friday' = friday. "
    "due_time: HH:MM when a time is said ('do 17' = 17:00), else empty.\n"
    "- not_before_day: the day work may start, only when the message says so "
    "('od środy', 'not before Wednesday').\n"
    "- min_chunk_minutes: when the user allows splitting, the shortest piece "
    "('w kawałkach min. godzinę' = 60, 'in 30-minute chunks' = 30). Empty when not said.\n"
    "- priority: high for 'ważne', 'pilne', 'important', 'urgent'; low for 'kiedyś', "
    "'low priority', 'when there's time'; otherwise normal.\n"
    "- If the message isn't a task, leave title empty and write a short reply.\n"
    "Example, categories Work, Learn, Home: 'raport kwartalny na piątek do 17, 3h, kawałki min "
    "godzinę, ważne' -> "
    '{"title":"raport kwartalny","category":"Work","duration_minutes":180,"due_day":"friday",'
    '"due_time":"17:00","min_chunk_minutes":60,"priority":"high"}'
)


def task_prompt(text: str, now: str, categories: list[str]) -> str:
    return f"now: {now}\ncategories: {', '.join(categories)}\nmessage: {text}"


def _hhmm(value: str | None) -> time | None:
    m = re.fullmatch(r"([01]?\d|2[0-3]):([0-5]\d)", (value or "").strip())
    return time(int(m.group(1)), int(m.group(2))) if m else None


def task_from_request(req: TaskRequest, categories: list[str], today: date,
                      task_id: str) -> tuple[Task | None, str | None]:
    """The task, or why there is none (said back to the user)."""
    title = req.title.strip()
    if not title:
        return None, req.reply or "Say what the task is, e.g. 'report for Friday, 3h'."
    if not req.duration_minutes or req.duration_minutes <= 0:
        return None, f"How long will '{title}' take? Add it, e.g. '{title}, 2h'."
    if req.duration_minutes >= 24 * 60:
        return None, "A task must be shorter than 24 hours; split it into several tasks."
    if req.category not in categories:
        return None, f"'{req.category}' is not one of your categories ({', '.join(categories)})."
    due = None
    if req.due_day:
        due = datetime.combine(resolve_day(req.due_day, today), _hhmm(req.due_time) or time(23, 59)).astimezone()
    not_before = None
    if req.not_before_day:
        not_before = datetime.combine(resolve_day(req.not_before_day, today), time(0)).astimezone()
    chunk = req.min_chunk_minutes
    if not chunk or chunk <= 0 or chunk >= req.duration_minutes:
        chunk = None
    return Task(id=task_id, title=title[:100], category=req.category, duration_min=req.duration_minutes,
                due=due, not_before=not_before, min_chunk_min=chunk, priority=req.priority), None
```

```python
    s["days"] = [date.fromisoformat(str(d)) for d in s["days"]]
    s.setdefault("categories", CATEGORIES)
    if s.get("routine", "default") == "default":
        s["routine"] = (SCENARIOS / "_routine.md").read_text()
    s["notes"] = s.get("notes") or ""
    s["expect"] = s.get("expect") or {}
    s["events"] = [Event(id=e["id"], calendar=e["calendar"], title=e["title"],
                         start=_dt(f"{e['day']} {e['start']}"), end=_dt(f"{e['day']} {e['end']}"))
                   for e in s.get("events") or []]
    s["tasks"] = [Task(id=t["id"], title=t["title"], category=t["category"], duration_min=t["duration_min"],
                       due=_dt(t["due"]) if t.get("due") else None,
                       not_before=_dt(t["not_before"]) if t.get("not_before") else None,
                       min_chunk_min=t.get("min_chunk_min"), priority=t.get("priority", "normal"))
                  for t in s.get("tasks") or []]
    return s


def score(s: dict, changes, problems: list[str], unscheduled: list[str]) -> list[str]:
    """What went wrong against the scenario's expectations; empty = pass."""
    fails = [f"rule: {p}" for p in problems]
    placed: dict[str, int] = {}
    first: dict[str, datetime] = {}
    for c in changes:
        if c.kind == "create" and c.task_id:
            placed[c.task_id] = placed.get(c.task_id, 0) + minutes(c.new_start, c.new_end)
            first[c.task_id] = min(first.get(c.task_id, c.new_start), c.new_start)
    tasks = {t.id: t for t in s["tasks"]}
    listed = {u.split(":", 1)[0].strip() for u in unscheduled}
    exp = s["expect"]
    for tid in exp.get("placed", []):
        if placed.get(tid, 0) < tasks[tid].duration_min:
            fails.append(f"{tid}: placed {placed.get(tid, 0)} of {tasks[tid].duration_min} min")
    for tid in exp.get("unscheduled", []):
        if tid not in listed:
            fails.append(f"{tid}: should be listed as unscheduled")
    for a, b in exp.get("before", []):
        if a in first and b in first and first[a] > first[b]:
            fails.append(f"soft: {a} should start before {b}")
    limit = exp.get("max_block_min")
    for c in changes:
        if limit and c.kind == "create" and c.task_id and minutes(c.new_start, c.new_end) > limit:
            fails.append(f"soft: {c.task_id} block {c.new_start:%a %H:%M}-{c.new_end:%H:%M} is over {limit} min")
    return fails


class Counting:
    """Counts the rounds plan_days needed (1 = right the first time)."""

    def __init__(self, inner):
        self.inner, self.rounds = inner, 0
        self.one_day_at_a_time = getattr(inner, "one_day_at_a_time", False)

    def plan_week(self, system, prompt):
        self.rounds += 1
        return self.inner.plan_week(system, prompt)


def _backend(name: str, model: str | None):
    if name == "ollama":
        from dayoptimizer.llm.ollama_backend import OllamaBackend
        return OllamaBackend(model=model or "qwen3:8b")
    from dotenv import load_dotenv
    load_dotenv(ROOT / ".env")
    from dayoptimizer.llm.anthropic_backend import AnthropicBackend
    return AnthropicBackend(model=model or "claude-sonnet-5-5")


def main(argv=None) -> int:
    p = argparse.ArgumentParser(description="Score the task scenarios against a model.")
    p.add_argument("--backend", choices=["ollama", "anthropic"], required=True)
    p.add_argument("--few-shot", choices=["on", "off"], default="on")
    p.add_argument("--only", default=None, help="run one scenario by file name, without .yaml")
    p.add_argument("--model", default=None)
    a = p.parse_args(argv)
    inner = _backend(a.backend, a.model)
    paths = [x for x in sorted(SCENARIOS.glob("*.yaml")) if a.only in (None, x.stem)]
    passed = 0
    for path in paths:
        s = load(path)
        backend = Counting(inner)
        try:
            changes, _, problems, unscheduled = plan_days(
                backend, s["days"], s["routine"], s["categories"], s["events"], s["notes"], [], s["now"],
                tasks=s["tasks"], left={t.id: t.duration_min for t in s["tasks"]}, few_shot=a.few_shot == "on")
        except Exception as exc:
            print(f"ERROR {s['name']}: {' '.join(str(exc).split())[:200]}")
            continue
        fails = score(s, changes, problems, unscheduled)
        hard = [f for f in fails if not f.startswith("soft:")]
        passed += not hard
        print(f"{'PASS' if not hard else 'FAIL'} {s['name']} ({backend.rounds} rounds)")
        for f in fails:
            print(f"    {f}")
    print(f"\n{passed}/{len(paths)} passed  backend={a.backend} few-shot={a.few_shot}")
    return 0 if passed == len(paths) else 1


if __name__ == "__main__":
    raise SystemExit(main())
```
